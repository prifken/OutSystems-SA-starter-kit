# SA Starter Kit

A minimal, self-contained component library for OutSystems Solutions
Architects to build customer-facing HTML prototypes fast during early
sales conversations. No build step, no npm, no framework — plain HTML,
CSS, and vanilla web components that open directly in a browser.

**Setup:** open Claude Code in this directory. Read `CLAUDE.md` for the
component library reference and the recipe for starting a new prototype.
The complete worked example lives in `examples/os-ticketing/` — open
`examples/os-ticketing/dashboard.html` in a browser to see it running.
